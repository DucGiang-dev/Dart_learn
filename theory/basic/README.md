# Nền tảng Dart & Flutter

Thư mục `theory/basic` dùng để lưu kiến thức nền tảng cho người mới bắt đầu.

Phần này bao gồm cả **Dart cơ bản** và **Flutter cơ bản**.

## Nguyên tắc học

Bạn nên học theo thứ tự:

```text
1. Dart cơ bản
2. Flutter cơ bản
3. Làm bài tập trong exercises
4. Làm lab trong labs
```

Lý do:

- Dart giúp bạn hiểu ngôn ngữ.
- Flutter giúp bạn dùng Dart để tạo giao diện ứng dụng.
- Nếu chưa hiểu Dart, học Flutter sẽ dễ bị khó ở phần widget, state và callback.

## Cách học hiệu quả

Với mỗi bài, bạn nên làm theo chu trình:

```text
1. Đọc mục tiêu bài học.
2. Đọc lý thuyết.
3. Đọc ví dụ.
4. Gõ lại code bằng tay.
5. Chạy thử.
6. Sửa code theo ý mình.
7. Làm bài tập nhỏ.
```

Không nên chỉ đọc mà không gõ code.

## Khi nào chuyển sang phần nâng cao?

Bạn có thể học `theory/advanced` khi đã hiểu:

- Biến, hàm, điều kiện, vòng lặp.
- `List`, `Map`, `class`.
- `Future`, `async`, `await`.
- Widget cơ bản trong Flutter.
- `StatelessWidget`, `StatefulWidget`.
- Layout cơ bản như `Column`, `Row`, `Container`, `ListView`.
