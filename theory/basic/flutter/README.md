# Flutter cơ bản

Thư mục `flutter` dùng để lưu kiến thức Flutter cơ bản cho người mới.

Bạn nên học phần này sau khi đã đọc các bài Dart cơ bản trong `theory/basic`.

## Vì sao học Flutter sau Dart?

Flutter dùng Dart để viết code.

Nếu bạn chưa hiểu Dart, bạn sẽ khó hiểu các khái niệm Flutter như:

- Widget.
- Callback.
- `StatefulWidget`.
- `setState`.
- `FutureBuilder`.
- Model data.
