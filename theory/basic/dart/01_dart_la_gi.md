# Bài 01: Dart là gì và dùng để làm gì?

## Mục tiêu bài học

Sau bài này, bạn cần hiểu:

- Dart là gì.
- Dart thường dùng để làm gì.
- Dart và Flutter khác nhau như thế nào.

## Lý thuyết

Dart là một ngôn ngữ lập trình do Google phát triển.

Ngôn ngữ lập trình là cách con người viết chỉ thị để máy tính thực hiện.

Ví dụ, bạn có thể dùng Dart để yêu cầu máy tính:

- In một dòng chữ ra màn hình.
- Tính toán điểm trung bình.
- Lưu danh sách sinh viên.
- Xây dựng giao diện ứng dụng bằng Flutter.

Dart thường được biết đến nhiều nhất vì nó là ngôn ngữ chính của Flutter.

## Dart và Flutter

Dart và Flutter không phải là một thứ.

```text
Dart = ngôn ngữ lập trình
Flutter = bộ công cụ dùng Dart để tạo giao diện ứng dụng
```

Ví dụ:

- Nếu bạn viết `print('Hello Dart')`, bạn đang dùng Dart.
- Nếu bạn viết giao diện mobile app bằng `MaterialApp`, `Scaffold`, `Text`, bạn đang dùng Flutter, nhưng bên trong vẫn viết bằng Dart.

## Khi nào dùng Dart?

Bạn có thể dùng Dart để học:

1. Lập trình cơ bản.
2. Lập trình hướng đối tượng.
3. Xử lý dữ liệu bất đồng bộ.
4. Phát triển ứng dụng Flutter.

## Ví dụ

Một chương trình Dart rất đơn giản:

```dart
void main() {
  print('Hello Dart');
}
```

Trong ví dụ này:

- `main` là nơi chương trình bắt đầu.
- `print` dùng để in thông tin.
- `'Hello Dart'` là một chuỗi ký tự.

## Ghi nhớ

- Dart là ngôn ngữ lập trình.
- Flutter dùng Dart để xây dựng ứng dụng.
- Khi mới học, bạn nên hiểu Dart trước, sau đó học Flutter sẽ dễ hơn.
