# Labs

Thư mục `labs` dùng để lưu các bài lab Dart và Flutter theo từng buổi học.

Mỗi lab thường tương ứng với một chủ đề hoặc một bài thực hành cụ thể.

## Cấu trúc tổng quan

```text
labs/
├─ LAB1...
├─ LAB2...
├─ LAB3...
├─ LAB4...
├─ LAB5...
├─ LAB6...
└─ LAB7...
```

## Gợi ý học theo thứ tự

### LAB1

Bài nhập môn Flutter/Dart.

Thư mục này hiện chứa tài liệu và file nén liên quan đến bài lab đầu tiên.

### LAB2

Bài thực hành Dart cơ bản.

Phù hợp để luyện:

- Biến.
- Kiểu dữ liệu.
- Hàm.
- Câu lệnh điều kiện.
- Vòng lặp.

### LAB3

Bài thực hành Dart bất đồng bộ.

Chủ đề chính:

- `Future`
- `Stream`
- `async`
- `await`

### LAB4

Flutter project thực hành giao diện cơ bản.

Entry point thường nằm trong:

```text
lib/main.dart
```

### LAB5

Movie app.

Chủ đề chính:

- Model.
- Danh sách dữ liệu.
- Màn hình danh sách.
- Màn hình chi tiết.
- Navigation.

### LAB6

Responsive movie browser.

Chủ đề chính:

- Responsive layout.
- Widget tách nhỏ.
- Model/data/widgets/screens.

### LAB7

Signup form.

Chủ đề chính:

- `StatefulWidget`
- `TextEditingController`
- `FocusNode`
- Form validation
- Password strength

## Cách học labs

Nên học labs sau khi đã đọc:

```text
theory/basic/README.md
```

Nếu gặp khái niệm chưa hiểu, hãy quay lại lý thuyết trước, sau đó quay lại lab.
