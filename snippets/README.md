# Snippets

Thư mục `snippets` dùng để lưu các đoạn code mẫu ngắn.

Mục tiêu của thư mục này là giúp bạn tra cứu nhanh các mẫu code thường dùng khi học Dart và Flutter.

## Snippets nên lưu gì?

Nên lưu các đoạn code ngắn, dễ đọc, dễ copy.

Ví dụ:

- Khai báo biến.
- Viết hàm.
- Tạo class.
- Dùng `List`.
- Dùng `Map`.
- `Future` và `async/await`.
- Widget Flutter cơ bản.
- Form validation.
- Navigation.
- State management đơn giản.

## Quy ước đặt tên snippet

Tên file nên mô tả rõ nội dung.

Ví dụ:

```text
variable_examples.dart
function_examples.dart
class_example.dart
future_async_await_example.dart
text_form_field_validation.dart
```

## Cách sử dụng snippets

1. Tìm snippet theo chủ đề.
2. Đọc code để hiểu ý tưởng.
3. Chạy thử trong project hoặc file Dart riêng.
4. Sửa giá trị đầu vào để xem kết quả thay đổi thế nào.
5. Chỉ copy vào bài làm khi đã hiểu code.

## Lưu ý

Snippet chỉ nên là ví dụ ngắn.

Nếu code đã thành một bài học hoàn chỉnh, nên đưa vào `theory` hoặc `exercises`.

Nếu code đã thành một project nhỏ, nên đưa vào `mini_projects`.
