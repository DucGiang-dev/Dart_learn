# Mini Projects

Thư mục `mini_projects` dùng để lưu các dự án nhỏ hoàn chỉnh hơn bài lab.

Mục tiêu của thư mục này là giúp bạn tổng hợp nhiều kiến thức đã học vào một project thực tế.

## Khi nào nên làm mini project?

Bạn nên làm mini project sau khi đã biết:

- Biến và kiểu dữ liệu.
- Hàm.
- `List` và `Map`.
- Class/object.
- Widget cơ bản trong Flutter.
- Navigation giữa các màn hình.
- Form cơ bản.

## Mini project khác gì với lab?

```text
Lab = bài thực hành theo chủ đề cụ thể
Mini project = project nhỏ hoàn chỉnh hơn, cần tự tổ chức code nhiều hơn
```

## Gợi ý project cho người mới

Bạn có thể bắt đầu với các project như:

- Ứng dụng ghi chú đơn giản.
- Ứng dụng quản lý chi tiêu.
- Ứng dụng danh sách việc cần làm.
- Ứng dụng xem phim đơn giản.
- Ứng dụng thông tin cá nhân.

## Quy ước nên có trong mỗi mini project

Mỗi mini project nên có:

```text
README.md
lib/
test/   nếu có kiểm thử
```

Trong `README.md` của project nên ghi:

- Project làm về gì.
- Cách chạy project.
- Các màn hình chính.
- Kiến thức Dart/Flutter đã sử dụng.
