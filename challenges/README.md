# Challenges

Thư mục `challenges` dùng để lưu các bài tập luyện tư duy lập trình.

Khác với `exercises`, phần `challenges` thường yêu cầu bạn tự phân tích đề và tự nghĩ cách giải.

## Cấu trúc

```text
challenges/
└─ leetcode/
   ├─ easy/
   ├─ medium/
   └─ hard/
```

## Mức độ bài tập

### `easy`

Dành cho người mới.

Nên làm khi bạn đã biết:

- Biến.
- Kiểu dữ liệu.
- `if/else`.
- Vòng lặp.
- Hàm cơ bản.

### `medium`

Dành cho người đã quen với bài dễ.

Nên làm khi bạn đã biết:

- `List`.
- `Map`.
- Hàm.
- Cách tách bài toán thành nhiều bước nhỏ.

### `hard`

Dành cho người đã có nền tốt.

Nên làm khi bạn đã tự tin với:

- Thuật toán cơ bản.
- Cấu trúc dữ liệu.
- Phân tích độ phức tạp.
- Tối ưu code.

## Cách học gợi ý

1. Đọc đề cẩn thận.
2. Viết ví dụ input/output ra giấy.
3. Nghĩ cách giải bằng lời trước khi code.
4. Code bản đơn giản nhất.
5. Chạy thử với nhiều trường hợp.
6. Nếu sai, kiểm tra từng bước.

## Lưu ý cho người mới

Không nên nhảy vào `medium` hoặc `hard` quá sớm.

Hãy làm chắc `easy` trước để rèn tư duy giải bài.
