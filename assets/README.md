# Assets

Thư mục `assets` dùng để lưu tài nguyên hỗ trợ cho tài liệu và project.

Tài nguyên ở đây không phải là code chính, mà là file hỗ trợ giúp tài liệu dễ hiểu hơn.

## Cấu trúc

```text
assets/
├─ diagrams/
└─ screenshots/
```

## `diagrams`

Dùng để lưu biểu đồ, sơ đồ hoặc hình minh họa.

Ví dụ:

- Sơ đồ cấu trúc repository.
- Sơ đồ luồng học Dart.
- Sơ đồ kiến trúc Flutter app.
- Biểu đồ giải thích `Future` và `Stream`.

## `screenshots`

Dùng để lưu ảnh chụp màn hình.

Ví dụ:

- Ảnh giao diện Flutter app.
- Ảnh kết quả chạy chương trình.
- Ảnh minh họa lỗi thường gặp.
- Ảnh so sánh trước/sau khi sửa UI.

## Quy ước đặt tên file

Tên file nên rõ nghĩa và dùng chữ thường.

Ví dụ:

```text
repo_structure.png
dart_learning_flow.png
signup_form_screen.png
movie_detail_screen.png
```

## Lưu ý

Không nên lưu ảnh không rõ mục đích.

Mỗi ảnh nên được dùng trong tài liệu hoặc project cụ thể.
