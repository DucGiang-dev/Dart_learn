# Bài tập Dart

Thư mục `exercises` dùng để lưu các bài tập từng bước cho người mới học lập trình.

Mục tiêu của thư mục này là giúp bạn luyện lại kiến thức đã học trong `theory/basic`.

## Cách học gợi ý

1. Đọc lý thuyết trong `theory/basic`.
2. Quay lại `exercises`.
3. Làm từng bài theo thứ tự.
4. Chạy code để kiểm tra kết quả.
5. Nếu sai, đọc lại lý thuyết tương ứng.

## Bài tập hiện có

```text
exercises/
├─ helloworld/
└─ 01_variables/
```

### `helloworld`

Bài đầu tiên để làm quen với chương trình Dart.

Bạn nên học:

- Cách tạo project Dart.
- Hàm `main`.
- Lệnh `print`.
- Cách chạy một file Dart.

### `01_variables`

Bài tập về biến và kiểu dữ liệu.

Bạn nên luyện:

- `int`
- `double`
- `String`
- `bool`
- `print`
- String interpolation

## Gợi ý cho người mới

Nếu bạn chưa biết bắt đầu từ đâu, hãy làm theo thứ tự:

```text
1. theory/basic
2. exercises/helloworld
3. exercises/01_variables
```

Đừng vội làm bài khó khi chưa hiểu biến, kiểu dữ liệu, `if/else` và vòng lặp.
