# Tài liệu học thuật Dart

Thư mục `docs` dùng để lưu các tài liệu học thuật và tài liệu thực tế do người phát triển viết ra.

Đây là nơi lưu kiến thức có tính hệ thống, dễ tra cứu và có thể dùng lâu dài trong quá trình học Dart/Flutter.

## Mục đích

Dùng `docs` cho các tài liệu như:

- Hướng dẫn học Dart/Flutter.
- Ghi chú kiến thức quan trọng.
- Tài liệu tổng hợp từ nhiều nguồn.
- Tài liệu thực tế do developer viết để giải thích cách làm.

## Không dùng docs cho

Không nên dùng `docs` để lưu:

- File kế hoạch nội bộ.
- Log chạy lệnh.
- File tạm.
- File chưa hoàn thiện và không có giá trị tra cứu.

## Quy ước đặt tên file

- Dùng chữ thường.
- Dùng dấu gạch dưới `_` để nối các từ.
- Tên file nên mô tả rõ nội dung.

Ví dụ:

```text
dart-learning-roadmap.md
flutter-widget-notes.md
async-dart-guide.md
```
