# Dart Learn

Chào mừng bạn đến với repository học Dart và Flutter.

Repository này được tổ chức theo hướng từ cơ bản đến nâng cao, phù hợp cho người mới bắt đầu học lập trình.

## Bắt đầu từ đâu?

Nếu bạn mới học lập trình, hãy bắt đầu theo thứ tự sau:

1. Đọc lý thuyết trong `theory/basic`.
2. Làm bài tập trong `exercises`.
3. Luyện tư duy lập trình trong `challenges`.
4. Học các bài lab trong `labs`.
5. Tham khảo code mẫu trong `snippets`.
6. Làm project nhỏ trong `mini_projects`.

## Cấu trúc repository

```text
.
├─ assets/          Tài nguyên hỗ trợ: biểu đồ, ảnh chụp màn hình
├─ challenges/      Bài tập luyện tư duy lập trình
├─ docs/            Tài liệu học thuật và tài liệu thực tế
├─ exercises/       Bài tập từng bước cho người mới
├─ labs/            Bài lab Dart/Flutter
├─ mini_projects/   Dự án nhỏ hoàn chỉnh hơn bài lab
├─ snippets/        Đoạn code mẫu ngắn
└─ theory/          Lý thuyết Dart
   ├─ basic/        Dart cơ bản
   └─ advanced/     Dart nâng cao
```

## Lộ trình học gợi ý

### Giai đoạn 1: Nhập môn Dart

Học tại:

```text
theory/basic/README.md
```

Nội dung nên học:

- Dart là gì.
- Biến và kiểu dữ liệu.
- `print()`.
- Toán tử.
- `if/else`.
- Vòng lặp `for`.
- Hàm.

### Giai đoạn 2: Làm bài tập cơ bản

Học tại:

```text
exercises/README.md
```

Sau khi đọc lý thuyết, hãy làm lại các bài tập nhỏ để nhớ kiến thức.

### Giai đoạn 3: Luyện tư duy lập trình

Học tại:

```text
challenges/README.md
```

Phần này giúp bạn luyện cách phân tích đề và viết thuật toán đơn giản.

### Giai đoạn 4: Làm lab Flutter

Học tại:

```text
labs/README.md
```

Phần này dành cho các bài thực hành Dart/Flutter theo từng buổi học.

### Giai đoạn 5: Làm project nhỏ

Học tại:

```text
mini_projects/README.md
```

Khi đã quen với Dart và Flutter cơ bản, bạn có thể làm các project nhỏ hoàn chỉnh hơn.

## Quy ước README

Mỗi thư mục quan trọng nên có `README.md` để trả lời các câu hỏi:

- Người học nên bắt đầu từ file nào?
